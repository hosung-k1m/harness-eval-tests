Determine whether each of the following sports teams is playing a game today (current calendar date):
- Cleveland Browns
- Ohio State Football
- Pittsburgh Steelers
- Atlanta Braves
- Philadelphia Phillies
- Western Kentucky Hilltoppers Football
- New York Yankees
- Los Angeles Lakers

Save the output to a file named `schedule.json` in the root of this environment directory.

The file must contain a valid JSON object mapping each team name exactly as listed above to a boolean (`true` if they are playing a game today, `false` otherwise).

Example format:
```json
{
  "Cleveland Browns": true,
  "Ohio State Football": false,
  "Pittsburgh Steelers": true,
  "Atlanta Braves": true,
  "Philadelphia Phillies": true,
  "Western Kentucky Hilltoppers Football": true,
  "New York Yankees": false,
  "Los Angeles Lakers": false
}
```
